# 按钮响应与切换性能核对（2026-10-24）

本轮集中处理高频交互的实际重复开销，并保留当前 Codex 桌面交互取向。参考 checkout 为 `.tmp/codex-src`，提交 `822e58cc3d666166c7446c5b1ea2e52f5d09594c`；阅读了 app-server 的分页历史读取与恢复链路，并观察了当前 Codex、MiniCode 的真实窗口。没有把旧 MiniCode 截图当成当前构建，也没有修改原用户窗口中的草稿或文件。

## 已落地的修复

- 聊天宽度变化只在摘要布局跨越阈值时更新摘要。聊天正文和输入区不再随侧栏动画每个像素重新渲染；工作区也跳过父级无关的能力通知。
- 等待切换确认时保留消息树、尺寸和输入状态，使用原有中央加载提示。后续水合刷新同一会话时，避免再次重置和恢复全部会话状态。真实后端确认仍决定当前 owner。
- 隐藏的聊天视口保留最后一次有效高度；ResizeObserver 直接消费浏览器测量值，宽度变化不再重复写入相同的回复高度。
- 设置分类拆分载入，访问过的页面继续保留草稿。右栏重用已打开的视图，避免父级布局更新带动多个隐藏面板重画。
- 左右侧栏每个展开动画只驱动一个宽度属性；右栏内容在裁剪区域中保持目标宽度。三个分隔条把同一帧的拖动合并，松手或丢失捕获时提交最后的位置。
- 能力快照在一次同步构建中复用各工具的权限判定和模型选择；下一次快照重新评估权限。公开实时语音能力使用已加载的模型目录，实际执行仍读取实际凭据。
- 沙箱探测完成只发布当前 scope 的实际权限结果，避免再构建和发送一次完整目录。前端合并该增量，保持模型、工具、技能和命令；没有目录字段的事件不再重复归一化已有目录。

没有增加跨会话权限缓存、重试系统、兼容层或吞异常逻辑。现有动效时长、真实状态与工具记录继续保留。

## 最终观测

以页面内 pointer/click 事件到相应状态可呈现的 RAF 回调计时。常规按钮测首个反馈；会话切换另外等待目标 owner 和后端水合完成。RAF 是呈现机会，不代表 GPU 已显示画面。早期包含 Playwright 等待的数秒统计不用于按钮响应结论，也不用于宣称加速比例。

| 操作 | 实测响应 | 样本 |
| --- | ---: | ---: |
| 左侧栏展开、收起 | 7.1–24.3 ms，中位数约 14 ms | 6 |
| 右侧栏展开、收起 | 12.6–23.6 ms，中位数约 15 ms | 6 |
| 已打开的右栏面板切换 | 10.7–21.4 ms，中位数约 15.1 ms | 11 |
| 设置分类首个反馈 | 3.2–25.5 ms，中位数约 16.2 ms | 16 |
| 首次显示设置页 | 77.8 ms | 1 |
| 聊天、模型菜单 | 21.4 / 13.9 ms | 各 1 |
| 搜索入口 | 11.7 ms | 1 |
| 会话完整恢复 | 606.6–1,932.1 ms，中位数约 1,266.6 ms | 5 |
| 定时任务页首次显示 | 243.2 ms | 1 |
| 多面板后返回首页 | 288.5 / 354.4 ms | 2 |

本轮不能声称“所有场景零掉帧”：右侧栏出现过 54.4 ms 帧间隔；初次外观、宠物和 Git 页面分别出现约 254.5 / 103.1 / 90.8 ms 间隔。多面板后返回首页和长会话完整恢复仍有明显峰值。这里保留这些结果，不把按钮首个反馈误写成全部数据已经完成，也不把无渲染异常等同于达到帧预算。

## 单列的验收边界

- 旧前端基线与同期更新的桌面 IPC 契约出现不匹配；一次副本准备还遗漏了原测试工作区的信任记录。这些运行失败，均未作为性能对比基线。没有为旧包增加生产兼容层。
- 中间脚本曾选错浏览器标签 ID、目标编辑器的前置状态及重名按钮，失败记录保留。最终 54 项实际操作已完成。
- 54 项操作完成后，Playwright 自动处理 Electron 关闭对话框发生 `Page.handleJavaScriptDialog: No dialog is showing`，导致那次脚本退出非零。窗口已关闭且没有残留该 QA profile 的 Electron 进程。脚本改为由桌面卸载协调器处理本机对话框后，独立 `close-check` 正常退出并记录 `closed: true`；不把原长跑退出码改写为通过。
- 本轮没有逐一操作破坏性提交、真实外部服务、全部附件格式、所有远程主机、MCP 应用或编辑器语言服务组合。静态库存和已有用例不作为这些 GUI 状态已通过的证明。
