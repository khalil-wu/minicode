# 归档、会话切换与编辑器索引性能修复（2026-10-08）

用户实际桌面日志中，Monaco `LanguageService._onDidChange` 同一时刻从 300 累积到 1500 个监听器，并触发异常。源码显示工作区索引为每个 TS/JS 源文件建立完整 TextModel，虽然同一份源码已交给 TypeScript worker 的 extra libs；隐藏源文件不需要这些完整编辑模型。

原生验收进一步捕获到 EEG 工作区连续 60 次全量索引请求和真实 60 秒超时。Windows watchdog 把 `LAST_ACCESS` 通知解释为修改；索引读取触发通知，前端按每条通知取消并重启请求，而取消 HTTP 并没有结束 `asyncio.to_thread` 中的扫描。该反馈链与模型暴增一起造成会话切换和归档时的资源争用。

## 修复范围

- 索引只复用打开或实际操作的模型，隐藏源码交给原生 worker。Problems 直接检查 worker 中的项目源码；项目符号逐文件使用并释放干净的临时模型，保留打开和修改过的模型。
- worker 明确同步当前 extra-lib snapshot，消除原生定时更新时序导致的旧工作区读取，并避免相同版本重复解析。
- Editor 与 Problems 共享工作区索引、请求和状态。读取期间合并通知与手动刷新，完成后补一轮；最后消费者退出才取消。待处理事件按路径保存最新事件及真实删除记录，不依赖最多 100 条的全局历史。
- 后端同一工作区共享扫描，最多 8 个在途文件读取。HTTP 最后消费者断开后协作取消，并等待真正的线程结束；取消期间加入的新消费者接续下一轮。每个消费者按进入时的 revision 读取，防止新页面接受修改前的旧扫描。
- 文件缓存随真实工作区 owner 生存，每轮重新遍历目录并检查打开句柄的 mtime/size/inode；写入、删除、重命名及工具修改使其失效。Windows watcher 移除访问时间订阅，保留实际写入、大小、名称和属性通知。
- 完整磁盘快照中缺失的打开源码标记磁盘冲突，保留草稿、模型和 Undo。删除或替换历史归属稳定的 tab ID，随草稿重命名保留，用户重新加载、保存或关闭后解除；新标签不继承旧冲突。
- 模型目录、agent 编辑器目录和工具规格读取已加载的配置元数据，移除重复凭据/Vault 解析；真实模型和图像执行仍读取真实凭据，密钥轮换回归保留。
- 摘要只检查真正发布摘要的 manifest/metadata，保留跨 repository 更新和删除可见性。归档复用同一次持久化后的 inventory，替代会话通过公开分页和后台上下文加载呈现。
- 主过程和旧工具卡移除“未获取有效内容”“抓取状态未确认”等附加标签。真实失败、部分结果和原始诊断保留；旧网页读取成功包装中的提取失败在同一操作行标明，不改写原始记录。

## 验证

TypeScript、最新生产构建和 kernel guard 通过。前端首批 12 个完整相关模块 **247 项通过**，后续统一验证共享请求与草稿所有权；按测试标识使用最新结果替换旧结果，去重后 **258 项通过，无失败或跳过**。包括 700 文件索引不创建模型、原生导航/重命名/跨文件 Undo、worker Problems、临时符号模型释放、250 条通知截断历史后仍保留删除冲突，以及关闭、重开和重命名的实际模型生命周期。

后端首批 **402 项：392 通过、10 失败、0 跳过**；一个失败捕获了目录仍经认证描述读取凭据的遗漏，其余是旧测试夹具没有提供新元数据或归档契约。完成修正并验证扫描、断连与 watcher 生命周期后，去重覆盖 **486 项通过，无剩余失败或错误，5 项跳过**。跳过项为一个 Linux inotify 专用用例和四个当前 Windows 无符号链接权限的用例，均未算作通过；新增真实 Windows 读取、写入和重命名回归通过。

独立生产调用链的相近负载测量中，EEGAgent 热切换完整上下文从 1489ms 降到 840ms，非当前会话归档从 940ms 降到 537ms，能力快照从约 400–640ms 降到 76–149ms。cProfile 放大了耗时，后续负载升高时的总时延也未用于宣称加速；桌面端响应仍需以实际窗口验证为准。
