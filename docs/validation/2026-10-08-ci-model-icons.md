## 模型选择

空闲时的模型和思考强度选择原来会读取凭据、刷新认证、创建适配器并重新绑定上下文，还会重扫 Skills 和探测沙箱。现在使用目录元数据校验并持久化选择，在请求进入执行阶段时读取真实认证并创建适配器。运行中的模型快照、客户端租约及下一步切换语义保留。

空白页与已有会话共用选择路径。模型变化仍更新实际工具模式；能力事件省略未变化的工作区目录，前端只在同一会话和工作区合并，切换 owner 或工作区会清理旧目录。真实事件校验到 store 的回归覆盖字段省略、工具变更、旧帧拒绝及不可重放契约。

## 图标

未知站点原来等待 Google S2→gstatic 图像完成，网络挂起时只留下空框。已移除第三方发现依赖，本地图标立即呈现，站点自身图标真正加载成功后替换。已知官方域名使用已打包的品牌资产，不根据文章标题猜品牌。修复 Markdown 通用图片样式覆盖单色品牌反色的问题。

有效文件链接、代码形式的文件引用和文件 citation 使用本地类型图标。普通代码、邮件、锚点及未确认的文件路径保留原语义；标签、范围、起始行列和导航行为不变。

## CI 与真实根因

- 收据测试依赖未跟踪的 `.tmp` 产物，改用仓库内脱敏的真实协议 fixture。
- Windows provisioning 测试还依赖本地下载归档。现跟踪固定 Codex 版本中补丁实际需要的 32 个未修改 Rust 源文件及原始许可证，干净离线 checkout 可执行同一 anchored patch；没有编造替代实现。
- Monaco 编辑器模拟与原生语言初始化边界不一致，统一测试边界；真实语言能力另有原生测试。
- 桌面资源路径测试硬编码 Windows 路径，改为宿主路径并保留资源、PATH 顺序断言。
- WebSocket 测试按实际事件类型、命令和会话读取，保留错误及持久化结果断言；模型创建本来就在请求阶段。
- CI 显式安装 ripgrep、clangd 和锁定的 Pyright/YAML Node 语言服务，保留真实搜索及语言服务集成。
- Linux 实际工具验证需要 Bubblewrap；CI 安装依赖后验证生产使用的文件系统和网络命名空间。只有宿主 AppArmor 确认限制用户命名空间时，给该测试 launcher 单独授权，仍使用真实隔离，没有改成无沙箱执行。Windows 专用测试只在模块内模拟平台，保留非 Windows 拒绝回归。
- sandbox 拒绝 glob 的 ripgrep 路径遗漏 symlink，统一已有文件系统扫描算法，保留别名、目标、深度、数量限制及扫描失败证据。
- 原生 viewport 测试采用既有隔离测试进程的 Linux 启动约定，使用独立临时 profile；生产 sandbox 和尺寸断言不变。
- 认证诊断保留模型目录和生成请求各自的真实证据，网络失败不会覆盖已确认的认证拒绝。
- 真实损坏历史恢复后，摘要和目录继续使用已恢复的可读版本；正常摘要仍不扫描历史文件，外部修复可使缓存失效。
- OAuth listener 关闭现在拥有并等待实际 TCP handler 和 stream 结算，覆盖 Python 3.11 及已接受、尚未分派 callback 的窗口；移除该边界的真实 socket 负向回归确实失败。Vue 搜索显式声明原生类型，避免系统 rg 版本改变结果，匹配与授权语义保留。
- 原生复查揭露返回缓存会话后页脚强度仍显示上一会话。模型、供应商和有效强度现共用同一投影规则，从会话快照、能力事件和 root_state 原子同步，按会话和工作区过滤，修正旧值错位；六个恢复入口经过实际 FooterRow 回归。
