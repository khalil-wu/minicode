## 修复范围

- 接纳与恢复：首条 durable 输入在实际串行接纳边界持久绑定会话；拒绝 ACK 结束对应的乐观回合；超长回合恢复采用冻结快照分页，按源事件序号合并后续直播。
- 执行与退出：取消真实 managed 工具任务；普通子任务退出前关闭自己的会话和后台命令资源；派生文件 Diff 失败不会阻断规范终态，真实错误仍写入执行日志。
- 模型：REST 与定时任务读取规范最终回复；贯通 Responses `end_turn=false` 的原生续跑；下调上下文窗口时先用原模型总结；补齐 Stop hook 和 reactive compact 的取消边界、vision 声明及 Anthropic 并行策略。
- MCP、Hook 与工具：按请求定位取消所有者，消费 elicitation Hook 的决策与结构化内容，持有异步 prompt Hook 的模型资源，将直接 MCP 图片保存为用户制品，统一扩展修改后的真实结果状态。
- 前端功能：slash 模板携带附件与引用并等待上传；取消旧搜索；同步 MCP 勾选草稿；清理过期浏览器上下文请求；更新前检查包含侧边聊天上传。
- 投影：普通滚动不再阻止最终答案收起过程；显式展开仍保留。主对话与子任务共用真实操作标题，移除“工具调用”泛化类别，明确的失败显示为“运行失败”等，未归类的真实操作与错误保留原行。Mermaid 使用顶层 `htmlLabels: false`，避免 SVG 清理后丢失节点文字。
- 编辑器：LSP 声明层级符号能力，并正确消费层级和扁平两种合法符号结果；请求取消使用 Monaco 的 `CancellationError`，保留真实服务器错误。
- 首次配置：协议连接与模型采样分离；未选择模型时仍能恢复会话、读取工作区、打开设置和工具目录，真实提问才要求并绑定模型。目录或注册刷新不隐式创建模型。未绑定客户端时，模型、思考强度、图像输入和并行策略仍按真实目录与配置声明投影，首次执行前后保持一致。
- 桌面更新：开发版本或未声明发布源的构建报告真实不可用，不初始化更新器或定时请求缺失的配置；有效捆绑源与明确运行时源仍正常检查。
- 参考图细节：成功启动行采用“实际名称开始工作”，完成状态同字号零间距，后续消息仅显示名称；按原图精修四瓣圆点及球面头像。浏览器/插件设置使用单组表面，外观低频选项归入高级披露，快捷键提供真实中文说明与铅笔入口。

对应审计的 F1–F9、R1–R15 与单列的 F10 协议缺口均有跨层或合同回归。没有通过隐藏错误、扩大恢复常数或添加虚构执行状态完成修复。
