# MiniCode UI 信息架构与视觉基线

本文件记录当前界面的真实数据来源、放置理由和视觉规格。目标是沿用 Claude Code、Pi、Codex 已验证的桌面 Agent 工作流，不为了“看起来功能多”增加没有运行链路的入口。

## 核心区域

| 区域 | 用户问题 | 真实来源 | 为什么放在这里 |
| --- | --- | --- | --- |
| 顶栏项目名 | 我现在操作哪个项目？ | `workingDirectory` | 项目作用域影响文件、终端和 Agent，必须始终可见。 |
| 顶栏新建任务 | 如何在当前模式开始一个独立任务？ | `createConversation({ appMode, bindWorkspace })` | 属于全局高频动作，不依赖当前消息。 |
| 顶栏终端 | 如何查看当前工作区的交互终端？ | desktop PTY / terminal store | 终端是工作区工具，不是聊天附件，因此放在全局工具区。 |
| 顶栏连接状态 | 后端能否执行 Agent 工作？ | WebSocket 连接状态 `isConnected` | 这是执行能力的总健康信号，只在断线时显示文字，正常时保持安静。 |
| 左栏任务与项目 | 我在哪个工作区、哪个会话？ | conversation store、workspace store | 负责导航与切换，不承载运行细节。 |
| 文件树 | 工作区里有哪些可编辑文件？ | 桌面端 `fsListTree/fsSearchFiles`；网页端 workspace API | 文件属于项目导航，选中文件转交编辑器；Git 标记来自 git store。 |
| 对话正文 | Agent 做了什么、结果是什么？ | WebSocket 消息流、工具事件投影 | 只保留可阅读的过程与结果，不把诊断字段直接堆给普通用户。 |
| 输入框 | 我接下来要让 Agent 做什么？ | composer draft、附件、权限和模型状态 | 固定在任务主轴底部；附件、权限、模型紧邻发送动作，因为它们共同决定下一次运行。 |
| 浮动上下文卡 | 本轮 Agent 正在引用什么？ | 消息 citations、附件、子智能体、当前会话后台进程、嵌入浏览器 | 只在存在真实上下文时出现；点击后转交右侧详情面板。 |
| 右侧“上下文” | 当前任务有哪些来源、产物和运行项？ | `buildActivitySidebarState` 汇总 workspace、messages、backgroundTasks、terminal、preview、subagents | 属于任务证据，靠近聊天但不打断阅读。 |
| 后台进程 | 哪些命令或服务仍在运行？ | 当前会话 `backgroundTasks`，以及 terminal / preview 运行状态 | 这里的“进程”是实际运行项，不是普通聊天步骤；点击会回到其所属终端、预览或任务面板。 |
| 运行详情 | 当前运行是否正常？ | conversation、Git、context usage、tool replay | 默认只显示状态、耗时和工作区；原始请求与性能追踪折叠到“高级诊断”。 |

## 设置页来源

| 设置分类 | 真实来源 / 动作 | 展示原则 |
| --- | --- | --- |
| 常规 | Zustand 持久偏好、权限模式、桌面更新接口 | 采用“标题 + 解释 + 右侧控件”的扫描结构；互斥权限使用单选语义。 |
| 模型 | `GET/PUT /api/llm/settings`、provider history、运行时能力检查 | 一个提供商一行；密钥只显示是否已配置，不回显明文。 |
| 连接 | `mcp.list`、MCP 生命周期命令、连接市场列表 | 服务状态和操作在同一行；添加表单与已安装服务分区。 |
| 已安排 | `scheduler.list` 与后端调度器 | 任务定义和最近运行结果属于同一能力，但不与普通后台进程混淆。 |
| 插件 | `GET /api/plugins`、插件状态、验证、导入、打包接口 | 插件开关会刷新技能和 MCP；开发操作单独放置，避免普通用户误以为必须配置。 |
| 实验功能 | runtime capability / feature override | 明确标为实验，不与稳定设置混排。 |
| 高级 | `env.list`、环境变量和运行时诊断 | 面向开发者，放在导航末尾。 |

## 视觉规格

- 基础节奏为 4px / 8px；同一设置行高 72px，列表型能力行约 82–88px。
- 字号：辅助说明 13px，导航 14px，设置项 15px，分组标题 17px，页面标题 28px。
- 圆角：搜索和导航 9–10px，设置卡片 17px，输入框 10px，输入区域 19px，浮动上下文卡 22px。
- 图标：通用动作和导航使用 Lucide 线性图标，导航 18px、行内动作 14–16px；模型和插件使用真实品牌图标或清单资源，放在 40–44px 图标容器中。
- 颜色只表达三类信息：当前选择、运行状态、风险。普通分组不使用彩色底板。
- 阴影只用于浮层、输入区域和右侧浮动卡；设置内容依靠边框、留白和分隔线建立层级。
- 没有数据时展示原因和真实下一步，不渲染零值装饰卡，也不增加无后端动作的按钮。
